# Día 2 linux desde cero
Hoy aprendí a desplazarme por la terminal de linux sin miedo
## Comandos que utilicé
-pwd---te dice la ubicación o directorio actual
-cd cambia de directorio, variantes que usé:cd .. (subir un nivel)
-usé rutas absolutas cd /home/robin/practica1 
-usé rutas relativas, ejemplo cd ../practica2
-usé comandos touch para crear uno o varios archivos al mismo tiempo, usé comando rm para eliminar uno o varios archivos al mismo tiempo
-Usé touch para crear uno o varios archivos desde otra ubicación usando rutas relativas o rutas absolutas, ejemplo touch ../practica2/archivo1.txt
## también usé touch ../practica2/{archivo2,archivo3,archivo4}.txt para crear multiples archivos desde otra ubicación
- apliqué los comandos anteriores pero eliminando uno o multiples archivos
- usé rm para eliminar archivos
- usé rmdir para eliminar directorios vaciós
- usé rm -r para eliminar directorios con archivos dentro, usé los comandos usando rutas absolutas y rutas relativas
- usé ls para listar archivos
