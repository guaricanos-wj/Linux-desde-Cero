# Día 1-Instalación de Ubuntu Server
Hoy instalé Ubuntu server como parte de mi proyecto de aprendizaje de Linux para ciberseguridad desde 0
## Lo que hice hoy
- Descargué Ubuntu server 22.04.5 LTS
- Instalé VMWare
- Configuré VMware para esa instalación con 8gb de ram, 30gb de almacenamiento, 4 procesadores, red privada virtual nat
- Realicé la instalación standard sin instalar paquetes adicionales
- configuré ip estática en modo nat
- activé el servidor OpenSSH para acceso remoto al server
- Aprendí que es LVM y por qué se usa en servidores
- verifiqué la conectividad de red
## Comandos usados:
- ip address show
- ping google.com
- ping -c 5 1.1.1.1
